# Stack Overflow Developer Survey Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Stack Overflow Developer Survey dataset.
It includes insights on developer demographics, employment, education, work hours, and country-wise statistics.

## Project Structure
- `Exploratory_Data_Analysis.ipynb` → Jupyter notebook with code & analysis
- `index.html` → fully rendered live HTML (graphs visible)

## How to View
- Open `index.html` in browser for full visualization
- Or open `.ipynb` notebook to see code and analysis

## Key Analysis
- Age, Gender, and Education distribution
- Country-wise programmer count
- Work hours vs Age & Country
- Visualizations: histograms, scatter plots, bar charts
